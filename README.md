# Skylrk Clone

A storefront clone project featuring phone cases and apparel products.

## Overview

This is a Shopify-based storefront clone showcasing:
- iPhone cases (various models)
- Apparel (hoodies, joggers, slides, beanies, socks)
- Desktop and mobile wallpapers

## Tech Stack

- HTML5 / CSS3
- JavaScript
- Shopify CDN assets

## Website Structure

```
├── index.html           # Main homepage
├── pages/              # Additional pages (FAQ, Contact, Privacy, etc.)
├── products/           # Product detail pages
├── cdn/                # CDN assets
└── repair_products.py # Product data repair script
```

## Getting Started

1. Open a terminal in the `skylrkclone` directory
2. Run the server:
   ```bash
   python -m http.server 8000
   ```
3. Visit `http://localhost:8000` in your browser
